# Pokémon Null Resources

The table below outlines additional resources available for Pokémon Null.

| Page | Description |
| --- | --- |
| [Pokédex](https://nulldex.pokemon0null.workers.dev/) | A complete referenece for Pokemon, encounters, moves, and abilities. |
| [Null website](https://pokemonnull.com/) | The main website for Null where you can access the patch to play it. |
| [Trainer battles](https://docs.google.com/spreadsheets/d/1mwHPt0AMzOJ_hfmDrVZpKP-Hf4eTT0ROhY8Wa7bY7r8/edit?usp=sharing) | Details on every trainer battle. |
| [Color-coded trainer battles](https://docs.google.com/spreadsheets/d/1ack17Gkn_sRG94HD9CP2UE0NcJ0RZz8FvBf6OgRxDMI/edit?usp=sharing) | Trainer battles with color-coding to identify Support Pokemon and dangerous abilities. |
| [Calculator](https://nullcalc.pokemon0null.workers.dev/) | The official damage calculator. |
| [Item Locations](https://docs.google.com/spreadsheets/d/1ForxCI9BczgfLYHEOTd-3Cg4tEa3Nn_VNk5nx-OLedo/edit?gid=1689048578#gid=1689048578) | Information about the locations of in-game items.  |
| [Master Sheet](https://docs.google.com/spreadsheets/d/16OKQJxnR0fDui9g4lhzx4x8qiCOTptAOYA8zDOn6h04/edit?usp=sharing) | A document that allow you to enter, track, and archive your data from your attempts of Pokémon Null. Also provides details on trainers, move changes, and AI behavior.
