# Pokémon Null Resources

The tables below outlines additional resources available for Pokémon Null.

## Official resources

| Resource | Description |
| --- | --- |
| [Null website](https://pokemonnull.com/) | The main website for Null where you can access the patch to play it. |
| [Pokédex](https://nulldex.pokemon0null.workers.dev/) | A complete referenece for Pokemon, encounters, moves, and abilities. |
| [Trainer battles](https://docs.google.com/spreadsheets/d/1mwHPt0AMzOJ_hfmDrVZpKP-Hf4eTT0ROhY8Wa7bY7r8/edit?usp=sharing) | Details on every trainer battle. |
| [Damage calculator](https://nullcalc.pokemon0null.workers.dev/) | The official damage calculator. |
| [Item locations](https://docs.google.com/spreadsheets/d/1ForxCI9BczgfLYHEOTd-3Cg4tEa3Nn_VNk5nx-OLedo/edit?usp=sharing) | Information about the locations of in-game items.  |
| [Pokémon locations](https://docs.google.com/spreadsheets/d/1EdJf2JRe5dLPEX1vWmbeRFeCIh-7hgos-t52JQd1Xb8/edit?usp=sharing) | Information about the locations of in-game Pokémon.  |
| [Move changes](https://docs.google.com/spreadsheets/d/17Vyr-bXeu9MGMZt_7dttb1OF8cuIcc5LihYmL0DEUu8/edit?usp=drive_link) | A complete list of any changes to the way moves behave. |
